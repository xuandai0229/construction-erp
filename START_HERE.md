## 🎮 How to Use

### Search
Type in search box → Results filter instantly

### Filter
Select filters → Click "Lọc" → Results update

### Pagination
Change page or items per page at bottom

### View Projects
Click the eye icon to view details

## 🛠️ Customize

### Change Colors
Edit: `app/globals.css`

### Add Projects
Use console:
```javascript
// Press F12, go to Console
const ProjectService = require('./app/project.service.ts').ProjectService;
ProjectService.createProject({ ... })
```

### Add Features
Add components to `app/` directory
